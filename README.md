# Machine Learning Lab

24 short Python lessons on statistics, text sentiment, regression, decision trees, classifier metrics, logistic regression and detection basics. Write code, press Check, get plain feedback. Everything runs in the browser, and progress stays on the device.

Run it: `python3 -m http.server 8765` in this folder, then open http://localhost:8765/index.html. The first run downloads Python packages (about 30 MB, cached after).
